# 个人资料

Owner 与普通会员均可在“账号安全 → 个人资料”修改自己的用户名和显示名称。
用户名不区分大小写唯一，待审核和禁用账号也占用名称；显示名称允许重复。

用户名先去除首尾空白并转为小写，要求 3–32 位、英文字母开头，只允许英文字母、
数字、`_`、`-`。显示名称去除首尾空白后必须非空，最多 80 个 Unicode 字符，支持中文。
历史 SSO 自动生成的长用户名可以保持不变，单独修改显示名称。

`PATCH /admin/profile` 接受可选的 `username` 和 `display_name`，至少提交一项，
成功返回 `user`。只校验提交的字段，不接受用户 ID、角色或其他字段。请求必须来自
同源且具备有效会话；提交用户名还要求五分钟内的密码、Passkey 或 SSO 身份验证。
SSO 验证返回后须重新提交保存，不自动改名。

资料按会话中的用户 ID 在同一事务内更新并写入审计。用户名占用返回
`409 username_taken`，同时提交的显示名称也不会保存。改名后旧用户名立即释放，
没有历史名称保留、冷却期或旧名登录别名；后续用户名登录使用新名称。
凭证、会话、API Key、设备、项目、账单与 SSO 绑定继续属于原账号。

页面刷新服务端状态时保留当前未保存输入，保存失败也保留输入；退出或切换账号
清除草稿。旧请求的迟到响应不能覆盖已保存资料或其他账号的页面。
恢复邀请通过[邀请管理](invitations.md)选择固定用户 ID，改名与旧名复用不改变目标。

本功能不需要数据库迁移，也不提供管理员代改功能。

测试范围、复现命令与桌面/手机截图见[验证记录](profile-validation.md)。
